# Módulo Recomendação Personalizada

> Fonte: `docs/source/DRS_LES_1_2026 (3).pdf`.

## Requisitos não funcionais

### RNF0044 — Recomendação com IA generativa

1. O sistema deve integrar uma IA generativa para oferecer recomendações personalizadas de livros aos clientes com base no histórico de compras e preferências.
2. A IA deve permitir a interação via chatbot para auxiliar na busca por livros, responder dúvidas e sugerir conteúdos relevantes.
3. O modelo de IA deve ser treinado com base em dados de vendas e feedback dos usuários, garantindo personalização contínua.
